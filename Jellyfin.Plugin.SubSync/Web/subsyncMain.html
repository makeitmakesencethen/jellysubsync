Synchronization Settings

How the engine decides which parts of the audio are speech. The default works for both film and TV.
How far from the video's audio the alignment may look for a subtitle's position. 180 by default: a subtitle can genuinely be minutes out, and an answer outside this window cannot be found. Too large invites matching the wrong place. A result that lands on the window is retried with twice it, and only written when the film's audio agrees.
How far a subtitle may be moved by an alignment taken from another subtitle track of the same file. Default: 30. A bigger shift is refused with the measured numbers: a reference track from a different cut drags every subtitle of the file onto it.
Maximum on-screen duration for a subtitle. Default: 10.
Lets the offset change across the timeline, for a file that is not one continuous cut (commercial breaks, inserted or removed scenes, discs joined into one file). 0 = a single offset for the whole file, which is what the plugin has always done. Values around 4-20 are typical; lower splits more eagerly. Default: 0.
The encoding the synced subtitle file is written in. Only the values the engine accepts are offered, so a typo cannot be saved and then silently written as UTF-8.

Multi-subtitle sync mode

Automatic (default) — adapts to the work: one subtitle stays sequential; several subtitles of one file share a single audio analysis and then run in parallel; several files run in parallel, each analysis reused.
Normal — one subtitle at a time, analysing the audio for each.
Parallel — several subtitles of the same file at once. CPU-bound, a few hundred MB per worker — keep it low on slow storage.
Fast — one audio analysis per file, reused by that file's other subtitles: measurably ~2-3× less work per extra subtitle. Helps only when several subtitles share a file.
Ultimate — Parallel + Fast.
Every mode produces the same alignments. The named modes are for troubleshooting; leave it on Automatic.
How many subtitles run at once in Parallel mode. Default: 4. Each wave covers different media files — several tracks of the same file never run at once. Reading subtitles out of the video runs in its own lanes, half this number and at most 3, because a lane reads a file while the workers align files already read. A higher value applies as soon as you save; a lower one as the extractions already running finish.
Checking…
Audio analysis — one file per media file, holding its speech signal so other subtitles of that file (and later runs) need not listen to the audio again. 30 days, 250 MB.
Extracted subtitle — the text taken out of a media file, so no file is read twice. 120 days, 512 MB on disk, and a bounded number held in memory for the files in flight.
Reference subtitle — the track a sync is aligned against. Kept only while that file's subtitles run.
Clearing removes all three, plus the scratch folders of finished jobs. It costs time only: everything is rebuilt when it is next needed.

Subtitle language filter

Leave empty to sync every language. Add one entry per language — anything else is never listed and never synced. Image-based tracks (Blu-ray PGS, DVD VobSub, DVB, XSUB) are excluded from the lists entirely, since they cannot be aligned. While a filter is set, text tracks with no language at all are skipped too, because they cannot be matched.
On by default: a subtitle timed for a different framerate (PAL 25 on a 23.976 fps file) is stretched onto the video's timeline, whether the alignment uses the audio or another subtitle. Turn it off when a subtitle from a different cut gets stretched instead — that case looks the same in the numbers, and the stretch then leaves the end of the film minutes out of step. Nothing is stretched silently either way: a result that is not a real framerate pair is refused with the numbers.
Searches harder for the exact stretch factor. Slower, and it only does anything together with Correct framerate mismatch above: while that is off the switch is unavailable and the engine is not given the flag.
Recommended (default): each sync writes a new file named "Title.SYNCED.srt" next to the original, so your subtitles are never touched. Replace overwrites the subtitle in place. Video files are never modified — embedded tracks are extracted and saved as a new external subtitle file instead of being remuxed back in.
