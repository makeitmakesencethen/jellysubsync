Synchronization Settings

                                

                                    
                                    
How the engine decides which parts of the audio are speech. The default works for both film and TV.

                                

                                

                                    
                                    
How far from the video's audio the alignment may look for a subtitle's position. 180 by default: a subtitle can genuinely be minutes out, and an answer outside this window cannot be found. Too large invites matching the wrong place. A result that lands on the window is retried with twice it, and only written when the film's audio agrees.

                                

                                

                                    
                                    
How far a subtitle may be moved by an alignment taken from another subtitle track of the same file. Default: 30. A bigger shift is refused with the measured numbers: a reference track from a different cut drags every subtitle of the file onto it.

                                

                                

                                    
                                    
Maximum on-screen duration for a subtitle. Default: 10.

Multi-subtitle sync mode

                                

                                    
                                    

                                        Automatic (default) picks per run: one subtitle on one file stays sequential;
                                        several subtitles of one file analyse the audio once and then run in parallel against that
                                        cached signal; several files run in parallel with each file's analysis reused. The other options force a specific behaviour —
                                        they exist for troubleshooting.
                                        Normal syncs one subtitle at a time and analyses the audio for each.
                                        Parallel runs several subtitles of the same media file at once (CPU-bound, a
                                        few hundred MB per worker — keep it low on slow storage).
                                        Fast analyses the audio once per media file and reuses that speech signal
                                        for the remaining subtitles of the same file, which is measurably ~2-3x less work per extra
                                        subtitle and produces identical results. Fast only helps when several subtitles share one
                                        file (a movie with many tracks, or re-syncing the same file later).
                                        Every mode produces the same alignments.
                                    

                                

                                

                                    
                                    
How many subtitles run at once in Parallel mode. Default: 4. Each wave covers different media files — several tracks of the same file never run at once.

                                

                                

                                    
                                    
Checking…

                                    
                                    

                                        Two things are cached. The audio analysis is one small file per media
                                        file, holding the speech signal so the other subtitles of that file (and later runs) do not
                                        listen to the audio again; unused entries are removed after 30 days and the cache is capped at
                                        250 MB. The reference subtitle is the track a sync is aligned against, kept only
                                        while that file's subtitles are being worked on. Clearing removes both, plus the scratch folders of
                                        finished jobs — it only costs time, since everything is rebuilt when it is next needed.
                                    

                                


                                
Subtitle language filter

                                

                                    
                                    

                                        Leave empty to sync every language. Add one entry per language — anything else is never
                                        listed and never synced. Image-based tracks (Blu-ray PGS, DVD VobSub, DVB, XSUB) are
                                        excluded from the lists entirely, since they cannot be aligned. While a filter is set,
                                        text tracks with no language at all are skipped too, because they cannot be matched.
                                    

                                    

                                        

                                            
                                            

                                        

                                        
                                    

                                    

                                    

                                

                                

                                    

                                        
                                        
On by default: a subtitle timed for a different framerate (PAL 25 on a 23.976 fps file) is stretched onto the video's timeline, whether the alignment uses the audio or another subtitle. Turn it off when a subtitle from a different cut gets stretched instead — that case looks the same in the numbers, and the stretch then leaves the end of the film minutes out of step. Nothing is stretched silently either way: a result that is not a real framerate pair is refused with the numbers.
