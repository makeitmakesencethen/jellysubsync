SubSync

Synchronize subtitles with video audio using ffsubsync.

ffsubsync Installation

Checking installation status...
Installs ffsubsync into an isolated Python virtualenv managed by this plugin — no system-wide pip needed. If python3 is missing, the plugin installs it automatically first (requires the Jellyfin process to run as root, the default in the official Docker image).

Synchronization Settings

The VAD method used by ffsubsync for speech detection.
Maximum allowed offset in seconds for any subtitle segment. Default: 60.
Maximum on-screen duration for a subtitle. Default: 10.
Encoding for the synced subtitle file. Default: utf-8.
Enable --gss to find optimal framerate ratio between video and subtitles.
Recommended (default): each sync writes a new file named "Title.SYNCED.srt" next to the original, so your subtitles are never touched. Replace overwrites the subtitle in place. Video files are never modified — embedded tracks are extracted and saved as a new external subtitle file instead of being remuxed back in.
Fast analyses the audio once per media file and reuses that speech signal for the remaining subtitles of the same file (identical results, noticeably less work per extra subtitle). It only helps when several subtitles share one file — a movie with many tracks, or re-syncing later. Normal and Parallel analyse the audio on every run.
How many subtitles run at once (1-64), used by Parallel mode and by Auto when it picks a parallel strategy. Default: 4. Whatever you enter is used as written. Each worker is CPU-bound and holds a few hundred MB while analysing audio, so raise it with the hardware in mind; a second subtitle of the same media file waits for the first one, since it reuses that file's stored audio analysis.
How long one embedded-subtitle extraction may take before it fails with a clear message instead of appearing to hang. Default: 20.
Comma-separated languages (codes or names — sv, swe and Swedish all match). Anything else is never listed and never synced, including the scheduled library sweep. Image-based tracks (Blu-ray PGS, DVD VobSub, DVB, XSUB) are hidden from every list because they cannot be aligned. While a filter is set, text tracks with no language are skipped as well.

Client Integration

To add the "Sync Subtitles" button to video detail pages, add the following to Dashboard → General → Custom client JavaScript:

<script src="/SubSync/ClientScript"></script>
